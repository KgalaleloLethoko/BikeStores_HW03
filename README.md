# BikeStore Management System

## Overview
A web-based bicycle sales management application developed using ASP.NET MVC and C#. The system provides a centralised platform for managing staff, customers, bicycle products, sales records and business reports.


## Features
- Dashboard: View staff, customer and product information.
- Staff & Customer Management:** Create, view, update and delete records.
- Product Management: Manage bicycle products and filter by brand and category.
- Sales Reports: Generate reports with graphical data visualisations.
- Document Archive: Save, download and delete generated reports.

## Technologies
- C#
- ASP.NET MVC 5
- Entity Framework
- Microsoft SQL Server
- HTML5 & CSS3
- Bootstrap
- JavaScript & jQuery
- LINQ / Lambda Expressions

## Getting Started

1. Clone the repository.
2. Open the solution in Visual Studio 2022.
3. Execute the provided BikeStores SQL script in SQL Server Management Studio.
4. Update the database connection string in `Web.config`.
5. Restore NuGet packages.
6. Build and run the application.
